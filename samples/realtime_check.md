### 조류경보제 조회서비스 (15126738) — 포털 설명에 적힌 것

- 주소: `https://apis.data.go.kr/1480523/nieragainstalgae` (지금 쓰는 수질 API와 같은 기관 번호 `1480523`)
- 상세기능 1개: 「조류경보제 측정결과조회」
- 요청변수: `serviceKey`, `pageNo`, `numOfRows`, `resultType`(XML), `ptNoList`(지점, 예: `3012A07`), `wmyrList`(연도, 예: `2023`), `wmodList`(월, 예: `01`)
- 출력 항목: 포털 페이지에는 `header`, `body`만 적혀 있고 세부 항목 이름은 없다.

## 3. 직접 불러 본 결과 (2026-11-15)

- 지금 수질 API 인증키로 위 주소를 불러 봄 → `NO_OPENAPI_SERVICE_ERROR`(코드 12, "해당 오픈API 서비스가 없거나 폐기됨").
- 이유로 보이는 것: **상세기능의 영문 이름(주소 끝부분)을 모른다.** 추측한 이름 두 개도 같은 오류였다. 활용신청도 아직 하지 않았다.
- → 활용신청 후 포털의 "미리보기"에서 실제 요청 주소를 확인해야 한다(1차 개발 때 수질 API와 같은 방법).

## 4. 활용신청 후 실제 응답으로 확인한 것 (2026-11-15 오후)

- 활용신청 승인. 상세기능 이름은 **`algaePreMeasure`** (포털 "활용신청 상세기능정보" 표에서 확인). 일일 트래픽 10000.
- 주소: `https://apis.data.go.kr/1480523/nieragainstalgae/algaePreMeasure`. 인증키는 지금 쓰는 `WATER_API_KEY`로 된다.
- `resultType=JSON`도 된다. 응답 모양은 수질 API와 같다:
  `{"algaePreMeasure": {"header": {"code": "00", "message": "NORMAL SERVICE"}, "item": [...], "totalCount"}}`
- `ptNoList`를 빼면 그달의 모든 지점이 온다(2026년 8월 289건, 지점 68곳).
- **자료가 최근까지 있다**: 2026-11-15에 11월을 요청 → 대부분 지점 **11월 9일**까지. (수질 자동측정 자료는 9월 30일까지인 것과 큰 차이)
- 측정 간격: 보통 **주 1번(월요일)**, 낙동강 하류 지점은 여름·가을에 **주 2번**. 하루 단위 연속 자료가 아니다.
- 날짜 `CHCK_DE`는 `"2026.11.09"` 모양(점으로 구분). 한 달을 요청하면 전달 마지막 며칠이 섞여 오기도 한다(9월 요청에 8월 31일, 10월 요청에 9월 28일). 응답 순서도 날짜순이 아니다.
- 낙동강 지점(코드가 `20…`): 상주보 `2007A25`, 낙단보 `2009A05`, 구미보 `2009A30`, 칠곡보 `2011A25`, 강정고령보 `2011A55`,
  해평 `2011G26`, 강정·고령 `2011G56`, 달성보 `2014A25`, 합천창녕보 `2014A70`, 창녕함안보 `2020A32`,
  **칠서 `2020G33`**, **물금·매리 `2022G05`**(가장 하류, 상세 주소 "취수구3km"), 호소: 공산지·영천호·진양호·운문호.
- 항목 이름(대문자): `SWMN_CODE` 지점코드, `SWMN_NM` 지점, `SWMN_DETAIL_NM` 세부지점, `RIVER_LKMH_SE` 하천/호소, `DETAIL_ADRES`,
  `CHCK_DE` 날짜, `IEM_WTRTP`, `IEM_PH`, `IEM_DOC`, `IEM_TRP`, `IEM_TUR`, `IEM_CHLA`, `IEM_BGALAGE_CELL_CO`,
  `IEM_BGALAGE_MICROSTS`, `IEM_BGALAGE_ANBA`, `IEM_BGALAGE_OSRTRIA`, `IEM_BGALAGE_APZO`, `IEM_GEOSM`, `IEM_MIB2`, `IEM_MICROSTLR`.
  값은 숫자도 **글자**로 오고, `"정량한계미만"`이라는 글자가 오기도 한다. 빈 값은 `null`.
- 물금·매리 2026-11-09: 수온칸 14.9, pH칸 7.3, `IEM_DOC` 10.2, 탁도칸 3.0, 클로로필칸 21.3, 남조류칸 7165.

## 5. 아직 모르는 것

- **항목의 뜻과 단위는 코드표로 확인하지 않았다.** 위 "수온칸" 같은 말은 이름 모양을 보고 짐작한 것이다.
  특히 `IEM_DOC`가 용존산소(DO)인지, 다른 것(예: 용존유기탄소)인지 모른다. 값(7~10)은 DO처럼 보이지만 추측으로 쓰지 않는다.
  → 포털의 참고문서 「조류경보제 측정결과조회_물환경_코드_코드명.xlsx」를 받아 확인해야 한다.
- 남조류 세포수 단위(보통 cells/mL로 알려짐), `BGALAGE_` 뒤 네 칸이 어느 조류 종류인지
- 경보 단계(관심·경계·대발생)는 응답에 **없다**. 단계를 보여 주려면 기준(문서)을 따로 확인해야 한다.
- 물금·매리 지점이 우리 양산(`S02056`) 측정소와 얼마나 가까운지(지도로 확인 안 함)

### 코드표를 읽어 본 결과 (2026-11-15, `samples/조류경보제 측정결과조회_물환경_코드_코드명.xlsx`)

- 시트 1개, **지점 목록만** 있다(구분·지점코드·지점명·조사위치·주소·조사기관·대권역·중권역). **항목(`IEM_…`) 설명은 없다.**
- 낙동강 하류 지점의 중권역: 물금·매리 `2022G05` = **낙동강하구언**, 칠서 `2020G33`·창녕함안보 `2020A32` = **낙동밀양**.
  조사기관은 셋 다 낙동강물환경연구소.
- 응답에 없던 지점도 있다: 조류참고지점(`…I…`, 예: 하굿둑 우안 `2022I20`·좌안 `2022I30`, 본포 취수구 `2020I37`),
  창녕함안보 창원칠서취수장 `2020A33` 등. 2026년 8~11월 응답에는 오지 않았다.
- 포털 페이지(15126738)의 출력 항목도 `header`, `body`뿐이다. 웹 검색으로도 `IEM_…` 이름 설명을 찾지 못했다.
- 포털 설명 글에 적힌 제공 항목은 "수온, pH, 투명도, 탁도, 유해 남조류 세포수, 클로로필-a, 우점종"이다.
  여기에 **용존산소는 없다.** 그래서 `IEM_DOC`를 DO로 볼 근거가 더 약해졌다.

### 물환경정보시스템 화면과 맞춰 본 결과 (2026-11-15)

- 화면: water.nier.go.kr → 자료조회 → 녹조(조류)정보 → **최근측정자료** → 조류 경보지점, 수계 "낙동강" 검색.
  화면 칸: 수온(℃), pH, DO(㎎/ℓ), Chl-a(㎎/㎥), 유해 남조류 세포수(cells/㎖), 발령 단계, 총 마이크로시스틴.
- 2026-11-09 세 지점의 값이 API와 **모두 같았다**:

  | 지점 | 수온 | pH | DO | Chl-a | 남조류 세포수 | 화면의 발령 단계 |
  |---|---|---|---|---|---|---|
  | 물금·매리 | 14.9 | 7.3 | 10.2 | 21.3 | 7,165 | 관심 |
  | 칠서 | 14.0 | 7.2 | 10.9 | 52.0 | 1,606 | 관심 |
  | 창녕함안보(함안) | 14.2 | 8.3 | 11.3 | 55.5 | 2,287 | 미발령(관찰지점) |

- 그래서 **확인된 뜻과 단위**(값 맞추기로 확인):
  `IEM_WTRTP` 수온(℃), `IEM_PH` pH, **`IEM_DOC` 용존산소 DO(㎎/ℓ)**, `IEM_CHLA` 클로로필-a(㎎/㎥),
  `IEM_BGALAGE_CELL_CO` 유해 남조류 세포수(cells/㎖).
  (앞에서 "포털 설명에 DO가 없으니 DO로 보지 않는다"고 했던 것은, 화면 값과 맞춰 본 결과 DO가 맞았다.)
- 화면 설명: 남조류 세포수는 Microcystis, Anabaena, Aphanizomenon, Oscillatoria 네 속 세포수의 합.
  API의 `BGALAGE_` 뒤 네 칸(MICROSTS, ANBA, OSRTRIA, APZO)을 더하면 `CELL_CO`와 같다(물금·매리 4840+0+0+2325=7165).
  어느 칸이 어느 속인지는 이름 모양으로만 짐작했다(문서 확인 아님).
- **아직 확인 못 한 것**: `IEM_TRP`(투명도로 보임), `IEM_TUR`(탁도로 보임), `IEM_GEOSM`, `IEM_MIB2`는 이 화면에 없다.
  `IEM_MICROSTLR`은 API 0.1, 화면 "총 마이크로시스틴" 0.19로 **달라서** 같은 것이라고 할 수 없다.
- **발령 단계는 API에 없고 화면에만 있다.** 발생현황지도 화면의 범례(상수원구간):
  관심 남조류 1,000 이상 / 경계 10,000 이상 / 대발생 1,000,000 이상. 친수활동구간: 관심 20,000 이상 / 경계 100,000 이상.
  (실제 발령은 "2회 연속" 같은 조건이 더 있을 수 있어서, 세포수 하나로 단계를 계산해 "발령"이라고 쓰면 안 된다.)
- 화면의 창녕함안보 채수위치는 "보 상류 300m", 코드표는 "보 상류 500m"로 서로 다르다.

## 5-1. 시간별 DO 자료를 찾아본 기록 (2026-11-16, 6차 탐구의 가설 (가)·(나)를 가르기 위해)

- 공공데이터포털 「수질 DB」(15081073) 4번 기능은 **하루 단위**만 준다(1차 개발 때 실제 응답으로 확인). 포털에서 다른 시간별 하천 수질 API는 찾지 못했다.
  (검색에 나온 「해양수산부_공동활용체계_수질자동측정망」은 바다 측정소라 관계없음.)
- 물환경정보시스템 → 자료조회 → **자동측정망**에 시간별 자료가 있다:
  - 「미확정 자료 조회」: 최근 2개월, **시간별/일별** 선택, 화면 조회만.
  - 「확정 자료 조회」: 2012-07-01 ~ 최근 2개월 전, **시간별/일별** 선택, CSV·EXCEL 내려받기 버튼 있음.
  - 「OPEN-API」: 공공데이터포털의 같은 '수질자동측정망 운영결과 DB'로 연결 → 하루 단위. 시간별 API는 없다.
  - 「파일셋 다운로드」: **국가수질자동측정망 시간자료** zip — 2012~2021년(2022-08-08 올림), 2022년, 2023년, 2024년, **2025년(2026-03-18 올림)**. 일자료 zip도 같은 해들.
- 아직 확인하지 않은 것: zip 크기, 파일 안 칸 이름, 낙동강 측정소와 DO 칸이 들어 있는지, 시각이 몇 시 단위인지.
- 주의: 시간자료는 **자동측정소**(예: 칠서 `S02007`, 양산 `S02056`) 자료다. 조류경보 지점(칠서 `2020G33`, 물금·매리 `2022G05`)과 같은 곳인지는 확인하지 않았다.

  → 같은 측정소 자료임을 확인. 단, 칠서 8/4는 시간자료가 5시간뿐이었는데 API 값은 비어 있었다(몇 시간 이상이어야 하루 값을 내는지는 모름).

- **양산 2025-08-04는 하루 평균 5.26이지만 최저는 4.0**이었다. 1차 개발 때 "하루 최저 DO는 이 자료로 구할 수 없다"고 했던 것을 지난 해 자료로는 구할 수 있게 됐다(빨강 규칙과 관련, 아직 바꾸지 않음).
